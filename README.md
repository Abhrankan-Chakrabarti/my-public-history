# my-public-history

A personal archive of exported Claude conversation logs, prompts, and chat sessions.

## Overview

This repository contains a static HTML archive of public conversations and session exports. The project is designed to keep the transcripts browsable offline in a simple, dependency-free format.

## Project structure

- `index.html` — searchable landing page for the archive
- `conversations/` — individual exported conversation pages
- `style.css` — archive styling
- `README.md` — project overview and usage notes

## How to view the archive

You can view the collection in either of these ways:

1. Open `index.html` directly in a browser.
2. Serve the folder locally:

   python -m http.server 8000

   Then visit http://localhost:8000

No build step or package installation is required.
