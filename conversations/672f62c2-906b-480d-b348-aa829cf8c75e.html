# 📚 Library Management System (React)

A minimalist **Library Management System UI** built using **React** and **Tailwind CSS**.
The project simulates core DBMS concepts such as book issuing, returning, stock management, issue tracking, and fine calculation using frontend state management.

---

## 🚀 Features

* 📘 View available books
* 👥 Manage members
* 📖 Issue books
* 🔄 Return books
* 📜 Live issue transaction registry
* 📦 Automatic stock updates
* 🚫 Prevent issuing out-of-stock books
* 🔢 Auto-generated issue numbers (sequence simulation)
* 💰 Fine calculation system
* 📊 Total issued counter for each book
* 🔍 Book search functionality
* 🎨 Responsive modern UI using Tailwind CSS

---

## 🛠️ Tech Stack

* React
* JavaScript
* Tailwind CSS
* Vite

# CampusLib Admin — Admin Dashboard for Campus Library

## v2.0.0 — Supabase Integration

### Breaking changes
- App no longer runs without a Supabase project. Copy `.env.example` → `.env`
  and fill in `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` before running.

### What's new
- All book, member, and issue data is now persisted in a hosted PostgreSQL
  database via Supabase — changes survive page refresh and are shared across
  sessions
- Fine calculation moved into a PostgreSQL trigger (`fn_return_book`), matching
  the original Oracle spec exactly
- Stock check and decrement on issue handled by `fn_return_book` DB trigger
- Supabase Realtime subscriptions added — changes made in one browser tab
  reflect instantly in all others with no polling
- Loading and error screens added for initial data fetch
- Buttons show a spinner and disable while async operations are in flight
- Supabase connection indicator in the sidebar

### Infrastructure
- Added `supabase/schema.sql` — run once in Supabase SQL Editor to provision
  tables, triggers, RLS policies, and seed data
- Added `src/lib/supabase.ts` — typed Supabase client singleton
- Added `src/types.ts` — shared TypeScript interfaces matching the DB schema
- Added `.env.example`
- Upgraded Vite 5 → 7 and `@vitejs/plugin-react` 4.3 → 4.7, clearing the
  esbuild moderate security advisory
- Fixed `JSX.Element` → `ReactElement` for React 19 compatibility
