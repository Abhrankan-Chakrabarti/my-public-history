Here's a breakdown of what DOB.py does:

Purpose: Takes a date of birth as input and prints a rich set of "fun facts" about that birthday.

Key features:

  • Input: Prompts for a date in DD/MM/YYYY format.
  • Age calculation: Computes exact age in years, months, and days, plus total days, hours, and minutes alive.
  • Zodiac info: Determines zodiac sign, ruling planet, birth flower, and birthstone based on the birth month/day.
  • Life path number: Uses numerology — repeatedly sums digits of the full date until reaching a single digit (or master numbers 11, 22, 33).
  • Generation label: Categorizes the birth year (e.g., Gen Z, Boomers, Gen Alpha).
  • Billionth second: Calculates the exact date when the person hits 1 billion seconds old.
  • Next birthday: Shows how many days until the next birthday, what weekday it falls on, and the one after that.
  • Sleep stats: Estimates time spent sleeping (assuming 8 hrs/day).
  • Calendar reuse: Finds the next year with an identical calendar.
  • Log file option: If run with -l or --log, saves the output to a .txt file.

A couple of things worth noting:

  • The generation() function is missing a return for years ≤ 1927 — it would return None for very old dates.
  • The format_number() function reimplements comma-formatting manually rather than using Python's built-in f"{n:,}".
  • The calendar-reuse formula (now.year + 14 - now.year % 14 + DOB.year % 14) is an approximation and won't always be accurate.

DOB_Facts_Calculator

DOB_Facts_Calculator is a Python script that generates interesting facts and statistics about a person's date of birth. The script calculates various details such as the life path number, zodiac sign, birthstone, birth flower, age in days, and significant milestones like the billionth second.

Features

  • Calculates life path number
  • Determines zodiac sign, ruling planet, birthstone, and birth flower
  • Computes age in years, months, and days
  • Provides the exact number of days, hours, and minutes lived
  • Identifies significant milestones like the billionth second
  • Outputs formatted information about your birth date

Usage

  1. Clone the repository:
    git clone https://github.com/Abhrankan-Chakrabarti/DOB_Facts_Calculator.git
  2. Navigate to the repository directory:
    cd DOB_Facts_Calculator
  3. Run the script:
    python DOB.py

Example

When you run the script, you will be prompted to enter your date of birth in the format DD/MM/YYYY. The script will then output a detailed log of facts and statistics about your date of birth.
